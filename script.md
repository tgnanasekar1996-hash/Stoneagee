# THE FIRST FLAME: 10-minute script

75 shots x 8 s = 10:00. Format: shot size | edit move | characters and expressions | action | **VO** | music | SFX.

Voice-over: one warm, gravelly male storyteller, slow pace (about 120 words per minute), recorded separately.
